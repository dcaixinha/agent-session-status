# Assets

The exact OpenCode square SVGs come from the
[OpenCode repository](https://github.com/anomalyco/opencode/tree/dev/packages/console/app/src/asset/brand)
and are available under the upstream MIT license in [`LICENSE.OpenCode`](LICENSE.OpenCode).
The project does not bundle Claude or OpenAI artwork. Users may configure local
provider images that they have the right to use; those files are not covered by
this project's licenses.

## Completion sound

`agent-complete.wav` is adapted from
[Hightech Notification 1](https://freesound.org/people/Tissman/sounds/522199/)
by Tissman, released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
It was amplified by 3.3 dB and trimmed to 100 ms of trailing silence.

The project code is MIT licensed. This sound is separately available under CC0 1.0.
